For Himnario Adventista MLC | Disclaimer:
This repo holds mp3 files for Cantado e Instrumental for SDA Hymnal v.2009 in Spanish. 
Those files have been made public on Archive.org and other websites.
Music works including music sheets, lyrics, audio files are property of own authors, composers. They are the only owners.
We added them in this repo to allow Himnario Adventista MLC App access them when devices have internet connection and users decide to play.
Users can choose singing or soundtrack mode, and MIDI for offline.
